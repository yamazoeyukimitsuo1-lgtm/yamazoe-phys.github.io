1. 数式（LaTeX）の表示テスト

MathJaxを導入しているため、LaTeX記法でそのまま数式を書くことができます。

独立した行に大きく表示するディスプレイ数式は $$ で囲みます。例えば、正規分布（ガウス分布）の確率密度関数は以下のようになります。

$$ f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(x - \mu)^2}{2\sigma^2} \right) $$

勾配降下法のパラメータ更新式なども綺麗に表示できます。

$$ \boldsymbol{w}^{(t+1)} = \boldsymbol{w}^{(t)} - \eta \nabla L(\boldsymbol{w}^{(t)}) $$

2. プログラムコードの表示テスト

Highlight.jsを導入しているため、<pre><code class="language-言語名"> で囲むだけで自動的に色分け（シンタックスハイライト）されます。文中の変数名やコマンドは numpy のようにインライン表示できます。

Pythonのコード例

import numpy as np

def gradient_descent(df, x0, lr=0.01, epochs=100):
    """シンプルな勾配降下法の実装"""
    x = x0
    for _ in range(epochs):
        grad = df(x)
        x = x - lr * grad
    return x

# f(x) = x^2 の最小値を求める (導関数 df(x) = 2x)
min_x = gradient_descent(lambda x: 2 * x, x0=5.0, lr=0.1)
print(f"Result: {min_x:.4f}")
